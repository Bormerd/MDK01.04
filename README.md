# Практическая работа №6: Документация для разворачивания проекта «Твой Репетитор»

## 1. Название проекта и его функционал
**«Твой Репетитор» (Desktop GUI Platform)** — это полнофункциональное десктопное приложение, разработанное для автоматизации взаимодействия между преподавателями (репетиторами) и студентами (учениками). Программный комплекс решает задачу быстрого поиска наставников, публикации учебных запросов и централизованного управления базой данных пользователей.

### Полный перечень реализованного функционала:
* **Мультиролевая система доступа:** Архитектура системы разделяет пользователей на три роли — Администратор (admin), Преподаватель (tutor) и Студент (student). Права доступа и видимость интерфейса строго разграничены на уровне СУБД.
* **Интерактивная и динамическая регистрация:** Экран создания аккаунта адаптируется под пользователя на лету. При выборе роли «Преподаватель» появляются поля для ввода предмета и часовой ставки. При выборе роли «Студент» эти поля скрываются, уступая место полям для ввода класса и целей обучения.
* **Личный кабинет Студента:** Позволяет ученикам публиковать свои индивидуальные заявки на обучение (указывая нужный предмет и максимальный бюджет), просматривать список своих активных запросов, удалять их при необходимости, а также осуществлять глобальный поиск по базе контактов всех зарегистрированных репетиторов.
* **Личный кабинет Преподавателя:** Предоставляет репетитору список всех студентов, которые ищут помощь именно по его дисциплине, отображая цели обучения ученика и его бюджет.
* **Панель Администратора:** Обеспечивает сквозной контроль над системой, позволяя просматривать полные таблицы всех зарегистрированных пользователей, список абсолютно всех созданных заявок, а также осуществлять безвозвратное удаление учетных записей нарушителей.
* **Комплексная система безопасности:** 1. Защита от подбора паролей (Brute-Force): после 3 неудачных попыток авторизации система полностью блокирует интерфейс ввода на 30 секунд.
  2. Защита от перехвата администрирования: встроенный валидатор жестко блокирует регистрацию любых Email-адресов, содержащих корень admin.
  3. Валидация сложности: пароль не примется системой, если в нем меньше 8 символов, нет хотя бы одной заглавной буквы, цифры и специального знака.
* **Журналирование действий (Логирование):** Все критические события (регистрация, успешный или провальный вход, удаление записей, смена настроек) записываются в изолированный текстовый лог-файл logs/app.log с фиксацией точного времени и роли пользователя.
* **Кастомизация и экспорт:** В приложении реализовано сохранение состояния интерфейса (светлая и тёмная темы оформления) между сессиями пользователя, а также функция резервного копирования данных в формат CSV.

## 2. Стек технологий
Для реализации проекта был выбран оптимальный, кроссплатформенный и легковесный стек технологий:
* **Язык программирования:** Python версии 3.10 или выше.
* **Графический интерфейс (GUI):** Библиотека CustomTkinter (модернизированный форк стандартного Tkinter, обеспечивающий современный UI со скруглениями элементов и нативной поддержкой темных/светлых стилей оформления).
* **База данных:** Встроенная реляционная СУБД SQLite3 (работает локально через файл tutor_platform_v2.db, не требует развертывания отдельного сервера баз данных).
* **Валидация и безопасность:** Модуль регулярных выражений re.
* **Дополнительные модули:** os (работа с директориями логов), time и datetime (таймеры блокировки интерфейса и метки времени), csv (выгрузка отчетов), sqlite3 (взаимодействие с данными).

## 3. Как установить (по шагам)
Для успешного развертывания программного продукта на целевой операционной системе выполните следующие шаги:
* **Шаг 1. Установка интерпретатора Python.** Перейдите на официальный сайт python.org, скачайте установщик Python версии 3.10+ для вашей ОС. При запуске установщика в обязательном порядке отметьте галочку «Add python.exe to PATH» (Добавить Python в переменные среды), после чего завершите установку.
* **Шаг 2. Размещение исходного кода.** Скачайте архив с проектом или клонируйте репозиторий. Распакуйте файлы приложения в отдельную рабочую папку на вашем компьютере (например, на Рабочий стол). Убедитесь, что файл ядра приложения app.py находится в корне этой папки.
* **Шаг 3. Запуск терминала.** Откройте командную строку Windows (CMD) или PowerShell, перейдите в папку с проектом с помощью команды cd (например: cd C:\Users\kpc\Desktop\Новая папка (4)).
* **Шаг 4. Установка графических зависимостей.** Находясь в терминале внутри папки проекта, введите и запустите команду для скачивания внешней библиотеки интерфейса: `pip install customtkinter`
* **Шаг 5. Контроль окружения.** Убедитесь, что процесс скачивания библиотеки завершился успешно (без ошибок со словом ERROR). Убедитесь, что у операционной системы есть права на чтение и запись в папку проекта, так как при запуске приложение начнет создавать файлы базы данных и папки для логов.

## 4. Как запустить (по шагам)
Для первичного запуска, конфигурации базы данных и проведения приемочного тестирования выполните следующие действия:
* **Шаг 1. Вызов главного скрипта.** Откройте терминал в папке с проектом и выполните команду запуска: `python app.py`
* **Шаг 2. Автоматическая инициализация СУБД.** При первом старте приложение самостоятельно создаст файл базы данных tutor_platform_v2.db, сгенерирует таблицы ролей, пользователей, заявок и добавит в систему учетную запись главного администратора по умолчанию.
* **Шаг 3. Первичный вход под администратором.** В открывшемся окне авторизации введите предустановленные разработчиком системные данные: Логин: `admin`, Пароль: `Admin123!`. Нажмите кнопку «Войти». Убедитесь, что открылся административный кабинет с тремя вкладками контроля.
* **Шаг 4. Тестирование создания аккаунтов.** Нажмите кнопку «Выйти», а затем выберите пункт «Создать аккаунт». Переключайте радио-кнопки «Я Ученик/Студент» и «Я Преподаватель» — убедитесь, что форма динамически перестраивает поля ввода. Зарегистрируйте одного студента и одного преподавателя, соблюдая правила безопасности (пароль с заглавной буквой, цифрой и спецзнаком; почта без слова admin).
* **Шаг 5. Проверка бизнес-логики и защиты.** Авторизуйтесь под созданным студентом, опубликуйте тестовую заявку, проверьте ее появление в таблице. Попробуйте удалить заявку и убедитесь, что всплывает модальное окно с предупреждением, что «все ваши котики умрут от грусти». Выйдите из аккаунта и введите три раза неверный пароль на экране входа — убедитесь, что система заблокировала ввод на 30 секунд. Проверьте появление файла логов по пути logs/app.log.
